نظام إضافة مجموعة موظفين - اختيار من Discord
===============================================

1) اضغط زر "إضافة مجموعة موظفين".
2) اختر الموظفين من قائمة أعضاء السيرفر بالترتيب المطلوب (حتى 25 موظفًا).
3) سيعرض البوت ترتيب الموظفين المختارين بالأرقام.
4) اضغط "إدخال البيانات".
5) اكتب سطرًا واحدًا لكل موظف بنفس ترتيب الاختيار، والصيغة:

الاسم | رقم الجوال | Citizen ID

مثال:
skeeen | 2050552702 | WSJ55173
Hasan afretah | 9070836237 | WS00713

لا تحتاج إلى Copy User ID أو منشن مكتوب. البوت يأخذ Discord User ID الحقيقي تلقائيًا من الاختيار.
إذا عدد الأسطر لا يساوي عدد الموظفين المختارين، لن يبدأ الاستيراد وسيطلب تصحيح العدد.
